# Investment Research MCP

A public home for a long-term, read-only MCP research toolkit covering portfolio context, investor disclosures, news, major product reveals, global indicators, geopolitical events, and commodity data.

## Current status

This repository is at the planning stage. The [community discussion](https://github.com/adwiteeymauriya/investment-research-mcp/discussions/1) sets out 41 sources to investigate over time and invites help choosing and validating the first integrations. The table is a work list, not a claim that tools or source access already exist.

The existing IBKR public MCP is a separate, already-connected source. This project is for research access only: no order placement, modification, cancellation, or other trading operations. Existing provider MCPs can be connected directly where suitable; custom adapters will be built only as needed. Crawl AI and Apify are possible options for sources that require web extraction, alongside source APIs and downloads where applicable.
