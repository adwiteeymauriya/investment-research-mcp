# Investment Research MCP

A public home for a long-term, read-only MCP research toolkit covering portfolio context, investor disclosures, news, major product reveals, global indicators, geopolitical events, and commodity data.

## Current status

This repository is at the planning stage. Its [source catalog discussion](https://github.com/adwiteeymauriya/investment-research-mcp/discussions) contains the full table of 47 candidate source rows: 41 selected for eventual MCP use and six retained for reference. Selection does **not** mean an integration exists, a first-party MCP server is available, or technical access has been validated. Sources will be added incrementally, not all at once.

The existing IBKR public MCP is a separate, already-connected source. This project is for research access only: no order placement, modification, cancellation, or other trading operations. Existing provider MCPs can be connected directly where suitable; custom adapters will be built only as needed. Crawl AI and Apify are planned options for sources that require web extraction, alongside source APIs and downloads where applicable.

## Discuss the sources

See [GitHub Discussions](https://github.com/adwiteeymauriya/investment-research-mcp/discussions) for the source table, selection status, access caveats, and candidate read-only operations. The catalog is a roadmap for evaluating sources—not a claim of implementation or live coverage.
